# purify-wpforms-lite 1.1.2

## English

Fixed: Normal WordPress updates are independent of the optional catalog, with bounded downloads and stricter package validation.

Misc: Bundles deckerweb Library 1.3.0 and Updater 2.4.0. Existing features and minimum requirements remain unchanged. Temporary component data is cleaned up reliably when multiple plugins are uninstalled together; form data stays unchanged.

## Deutsch

Behoben: Normale WordPress-Updates sind unabhängig vom optionalen Katalog, mit begrenzten Downloads und strengerer Paketprüfung.

Sonstiges: Enthält deckerweb Library 1.3.0 und Updater 2.4.0. Bestehende Funktionen und Mindestanforderungen bleiben unverändert. Temporäre Komponentendaten werden auch bei gemeinsamer Deinstallation mehrerer Plugins zuverlässig bereinigt; Formulardaten bleiben unverändert.
