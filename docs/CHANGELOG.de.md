# Änderungsverlauf

### 1.1.2 · 2026-11-09

- **Behoben:** deckerweb Library auf 1.3.0 und Updater auf 2.4.0 aktualisiert: normale Updates unabhängig vom Katalog, begrenzte Downloads und strengere Paketprüfung.
- **Behoben:** Temporäre Komponentendaten werden auch bei gemeinsamer Deinstallation mehrerer Plugins zuverlässig bereinigt; Formulardaten bleiben unverändert.

### 1.1.1 · 2026-10-22

- **Verbessert:** Gemeinsamen Katalog und GitHub-Updater aktualisiert; Dokumentation übersichtlicher verlinkt.
- **Behoben:** Der Änderungsverlauf hat einen Dokumentations-Fallback und lässt sich auch bei überschriebenen Dialogmethoden schließen.
- **Sonstiges:** PHP 8.1 oder neuer ist erforderlich; WordPress 6.7 bleibt unterstützt.

### 1.1.0 · 2026-10-10

- **Neu:** Gemeinsamer Katalog, GitHub-Updater und zugänglicher lokaler Änderungsverlauf.
- **Verbessert:** Gründlichere Bereinigung entfernt Premium-Eintragswerkzeuge, Gutschein-Upsells, Einrichtungs-Checkliste, WPVibe-/WPCode-Werbung und Werbe-Widgets; nutzbare Lite-Bedienelemente bleiben erhalten.
- **Verbessert:** Eigenständige lokalisierte Banner und Icons verwenden eine klare Formulargrafik.
- **Behoben:** Unbekannte Zielversionen pausieren sicher; mitgelieferte deutsche Übersetzungen werden geladen.
- **Sonstiges:** PHP 8.0 ist jetzt erforderlich. Newsletterlinks enthalten keine persönlichen Kontodaten. Snippet-Importe bleiben verfügbar.

### 1.0.0 · 2025-04-05

- **Neu:** Erste öffentliche Veröffentlichung.
